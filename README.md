#Cifra de César - Criptografia e Criptoanálise#

Este projeto é uma ferramenta desenvolvida para demonstrar os fundamentos da segurança da informação através da clássica Cifra de César. 
A aplicação permite a ofuscação de textos, a recuperação de dados através de chaves simétricas e conta com um módulo de auditoria que demonstra a vulnerabilidade do algoritmo aplicando um ataque de Força Bruta.

#Funcionalidades:

*Criptografia: Oculta mensagens aplicando um deslocamento (chave) aos caracteres do texto original.
*Descriptografia: Reverte o processo de criptografia para revelar a mensagem original, desde que a chave de deslocamento seja conhecida.
*Criptoanálise (Força Bruta): Quebra a criptografia testando sistematicamente todas as chaves de deslocamento possíveis até que a mensagem legível seja encontrada, sem a necessidade de conhecimento prévio da senha.

*Bibliotecas: Nenhuma dependência externa (Built-in).

# Caesar Cipher - Cryptography and Cryptanalysis
This project is a tool developed to demonstrate the fundamentals of information security through the classic Caesar Cipher. 
The application allows text obfuscation, data recovery using symmetric keys, and features an auditing module that demonstrates the algorithm's vulnerability by applying a Brute Force attack.

#Features:

*Encryption: Hides messages by applying a shift (key) to the characters of the original text.
*Decryption: Reverses the encryption process to reveal the original message, provided the shift key is known.
*Cryptanalysis (Brute Force): Breaks the encryption by systematically testing all possible shift keys until a readable message is found, without needing prior knowledge of the password.

#Technologies Used:

*Language: Python 3.13.1
*Libraries: No external dependencies (Built-in).
